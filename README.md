Aplicação web desenvolvida para calcular valores de frete com base em **peso, distância e fidelidade do cliente**, aplicando regras de negócio dinâmicas com JavaScript puro.

---

## 🎯 Objetivo do Projeto

Projeto criado para praticar:

- Manipulação de formulários  
- Validação de campos  
- Manipulação de parâmetros via `URLSearchParams`  
- Lógica condicional (`if/else`)  
- Cálculos matemáticos  
- Manipulação do DOM  

---

## ⚙️ Regras de Negócio

### 📦 Cálculo por Peso
- R$ 5,00 por Kg

### 🛣️ Cálculo por Distância
- Até 100 km → valor normal  
- 101 a 300 km → acréscimo de 15%  
- Acima de 300 km → acréscimo de 30%  

### ⭐ Cliente Fidelidade
- 10% de desconto sobre o valor total do frete  

---

## 🖥️ Funcionalidades

✔ Captura dados do formulário  
✔ Validação de campos obrigatórios  
✔ Redirecionamento com parâmetros na URL  
✔ Cálculo automático do frete  
✔ Exibição detalhada do valor final  
✔ Aplicação dinâmica de desconto
